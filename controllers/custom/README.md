# Custom controllers

Reserved for controllers built with the app's **Controller Setup** tab rather
than hand-transcribed from official docs (see `catalog/__init__.py` and
`gui/controller_setup.py`). "Generate catalog module…" writes
`reference_image='custom/<filename>'` into the generated `catalog/<slug>.py`
module; copy the attached reference image here (`controllers/custom/<filename>`)
if you want it bundled with the app.

Nothing is copied here automatically, and nothing under this directory is a
built-in, official profile — see `../README.md` for those.
