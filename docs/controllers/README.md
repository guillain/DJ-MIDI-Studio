catalog. The local PDFs are kept as stable project references; the links below
are the manufacturer's original sources or the official product/documentation
pages where no MIDI message-list PDF is published.

## How to extend this index

When adding a controller, record the exact vendor URL, archive the PDF when
licensing and repository size allow it, and note whether it is a MIDI message
list, a user guide, or only a physical product reference. A product image must
not be described as an annotated MIDI map. Until a message list or hardware
capture exists, keep the corresponding profile conservative and mark it as
provisional in `TODO.md`.
