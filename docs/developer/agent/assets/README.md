## How to use these assets

1. Read [`CLAUDE.md`](../../../../CLAUDE.md) when working on implementation.
2. Copy [Task Template](task-template.md) into the agent request or working
   note and fill every relevant section.
3. Add [Project Context](project-context.md) for a compact, provider-neutral
   briefing.
4. Use [Review Checklist](review-checklist.md) before hand-off or merge.

These are prompts and checklists, not hidden instructions. The user’s request,
repository policy, and security constraints always take precedence.

## Maintenance rules

- Keep assets in English and use relative links.
- Prefer stable constraints over temporary task details.
- Update the index when adding or removing an asset.
- Never store secrets, private mappings, tokens, or machine-specific paths.
- Link to source documentation instead of copying copyrighted material.
