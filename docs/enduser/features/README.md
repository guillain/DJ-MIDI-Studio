## Highlights

| | Feature | In one line |
| --- | --- | --- |
| 🎛️ | [Controller Setup](controller-setup.md) | Teach the app any controller by pressing its buttons — no manufacturer docs needed |
| ⟳ | [Controller Sync](controller-sync.md) | One click puts every connected controller in its starting state |
| 📡 | [Live Monitor](live-monitor.md) | Every MIDI message, named and mapped, with the whole app lighting up as you play |
| 🎵 | [Music Library](music-library.md) | Bulk tag fixes, Camelot keys, genre categories and harmonic playlists for Serato and Traktor |
| 🕹️ | [Controller Emulator](controller-emulator.md) | A clickable twin of your controller, with pad modes, SHIFT and real MIDI output |
